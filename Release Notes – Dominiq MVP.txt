### Примечания

- После обновления рекомендуется выполнить полный сброс и перезапуск:
  ```bash
  docker compose down -v
  docker compose up -d
  ```
- Для корректной работы модели `phi3:mini` необходимо загрузить её в Ollama:
  ```bash
  docker exec -it dominiq-ollama ollama pull phi3:mini
  ```
- Все новые функции логируются и отображаются в Kibana (доступна по адресу `http://localhost:5601`).
