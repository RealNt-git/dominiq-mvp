## Создание дашбордов в Kibana для анализа логов

Отлично, теперь, когда логи поступают в Elasticsearch и отображаются в Kibana, мы можем создать информативные дашборды. Они помогут быстро визуализировать, что происходит в приложении: количество ошибок, активность пользователей, загрузку документа и т.д.

### 1. Что такое дашборд в Kibana?
Дашборд — это набор визуализаций (графиков, таблиц, счётчиков), собранных на одной странице. Вы можете добавлять, редактировать и сохранять их для постоянного мониторинга.

### 2. Полезные визуализации для вашего приложения
- **Количество логов по уровням** (INFO, WARNING, ERROR) – увидите, сколько ошибок происходит.
- **Активность во времени** – график количества логов за последние 15 минут/час/день.
- **Топ сообщений** – какие сообщения чаще всего встречаются (например, частые ошибки).
- **Логи по контейнерам/модулям** – если добавите поле `container_name` или `logger`, можно фильтровать.
- **Время обработки документа** – если логируют длительность, можно построить гистограмму.

### 3. Пошаговое создание первого дашборда

#### Шаг 1. Откройте Kibana
Перейдите по адресу: http://localhost:5601

#### Шаг 2. Перейдите в раздел визуализаций
- В левом меню нажмите **Visualize Library** (или **Dashboard** → потом создать визуализацию).
- Если меню свернуто, нажмите на гамбургер-меню слева вверху и выберите **Visualize Library**.

#### Шаг 3. Создайте новую визуализацию
- Нажмите кнопку **Create visualization**.
- Выберите тип визуализации, например **Line** (линейный график) или **Bar chart** (столбчатая диаграмма).
- В качестве источника данных выберите ваш Data View: `dominiq-logs*`.

#### Шаг 4. Настройте оси
- **Горизонтальная ось (X‑axis)**: выберите агрегацию **Date Histogram** с полем `@timestamp`. Это покажет время.
- **Вертикальная ось (Y‑axis)**: оставьте **Count** (количество документов). Получится график активности логов по времени.
- Нажмите **Update** (внизу), чтобы увидеть результат.

#### Шаг 5. Сохраните визуализацию
- Нажмите **Save** вверху, дайте название, например "Logs over time".

#### Шаг 6. Добавьте визуализацию на дашборд
- Вернитесь в **Dashboard** (через меню).
- Нажмите **Create dashboard**.
- В новом дашборде нажмите **Add an existing** и выберите только что созданную визуализацию.
- Разместите её на поле.
- Сохраните дашборд (например, "Dominiq Logs Overview").

### 4. Добавление фильтра по уровню (например, только ошибки)

Вы можете создать визуализацию, показывающую только ошибки:
1. Создайте новую визуализацию (например, **Bar chart**).
2. В конструкторе добавьте фильтр: нажмите **Add filter** (справа вверху) и укажите `level: "ERROR"` (если поле `level` есть в логах; у нас оно должно быть благодаря `python-logstash`).
3. Настройте оси так же (Date Histogram для X, Count для Y).
4. Сохраните и добавьте на дашборд.

### 5. Добавление таблицы с последними ошибками

- Создайте визуализацию типа **Data table**.
- В качестве метрик оставьте **Count**.
- В качестве корзины (Buckets) выберите **Split rows** и укажите поле `message` (агрегация **Terms**). Это покажет, какие сообщения встречаются чаще всего.
- Можно добавить фильтр по `level: "ERROR"`, чтобы видеть только ошибки.
- Сохраните.

### 6. Добавление счётчика (метрики)

- Создайте визуализацию типа **Metric**.
- В метриках выберите **Count**.
- Можно добавить фильтр, например, `level: "ERROR"`, чтобы показывать количество ошибок за выбранный период.
- Сохраните.

### 7. Настройка временного диапазона

На дашборде в правом верхнем углу можно выбрать период (Last 15 minutes, Last hour, Today и т.д.). Это влияет на все визуализации.

### 8. Советы

- Если поля `level`, `logger` не отображаются в Kibana, возможно, они не извлекаются из логов. Но `python-logstash` обычно добавляет их автоматически. Проверьте в Discover, какие поля есть у ваших логов.
- Чтобы увидеть поля, разверните любой документ в Discover — там будут все поля.
- Если нужно больше примеров, можете сообщить, я помогу настроить конкретные визуализации.

### 9. Дальнейшие шаги

После создания дашборда вы можете:
- Добавить ещё визуализации, например, по контейнерам (если есть поле `container_name`).
- Настроить алерты (например, при превышении порога ошибок).
- Поделиться дашбордом с коллегами (экспорт/импорт).

Если на каком-то шаге возникнут трудности, пришлите скриншот — разберёмся.
